# UK Government APIs OKF profile v1

Status: producer-specific profile, implemented 24 November 2026.

This document extends the common OKF 0.3 repository contract with the local
rules for this frozen API catalogue. It does not replace the common
[Bundle Wiki v2 profile](../bundle-wiki/v2/).

## Source and identity boundaries

- The published corpus is the reviewed 16 July 2026 snapshot. Migration and
  routine build commands use checked-in inputs only; they do not query upstream
  APIs or refresh the snapshot.
- Markdown under `bundle/api-records/`, `bundle/organisations/` and
  `bundle/docs/` is the typed core layer. `bundle/index.md` and `bundle/log.md`
  remain navigation and history files outside the concept graph.
- `bundle/okf-core-explorer.json` exposes every typed core document with its
  complete frontmatter, body, path, byte length and SHA-256. Its relationships
  come only from authored Markdown links.
- The larger API metadata catalogue is a profile extension. Metadata-only
  records are labelled `core_role: extension`; records with a corresponding
  typed Markdown concept and organisations with a typed Markdown concept are
  labelled `core_role: concept`.
- Preserve existing semantic identifiers and all 278,156 assertion identities
  and directed triples. Adding the core-role labels does not recast catalogue
  assertions as OKF core relationships.

## Synthetic Wayfinder comparison

Wayfinder material remains a separate, opt-in synthetic source. Its 85 demo
services and related assertions retain synthetic authority, synthetic scope
and rights-not-specified. Those assertions remain rejected from real-world
catalogue admission and must not be treated as evidence about a live government
service.

## Limits

The bundle is a frozen metadata snapshot. It does not establish current API
availability, endpoint behaviour, security, accessibility, licence sufficiency
or operational readiness. Source-reported, inferred and synthetic information
remain distinguishable. The Explorer's default relationship runtime is
bounded; the full graph remains available from its declared semantic shards.
